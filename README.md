# Generador de QR Portable
## Descripción:
- Este programa Genera Códigos QR en tiempo real usando las librerías de Python, está pensada para correr en Windows 11 (.exe) o Linux (.AppImage)

## Funciones:
- Crear QR Manualmente
- Automáticamente
- Agregar el URL en la imagen del QR
- Guardar en formato .JPG y .PNG
- Menú contextual que permite Copiar el QR sin guardarlo
