# Generador de QR Portanble
## Descripcion:
- Este programa Genera Codigos QR en tiempo real usando las librerias de python, esta pensada para correr en windows 11 (.exe) o Linux (.AppImage)

## Funciones:
- Crear QR Manualmente
- Automaticamente
- Agregar el URL en la imagen del QR
- Guardar en formato .JPG y .PNG
